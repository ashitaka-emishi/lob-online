## Technical Notes

The E2E smoke test should use the existing Vitest server test harness (not a Playwright browser test), creating a real in-memory game state and exercising the API routes + socket events end-to-end. Document the exact `npm run` command to run it.

For the a11y fix, prefer `aria-disabled` with a click guard over actually disabling the button — this preserves focus and allows screen readers to announce the reason. An `aria-live="polite"` region can announce pending/complete state changes.

The action contract doc should live at `docs/designs/action-contract.md`.
