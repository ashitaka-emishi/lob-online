## Summary

Replace the placeholder `StatusView` at `/` with a styled app home page that provides entry
points to the lobby and editor tools. Add a small navigation menu to each editor/tool page so
users can move between surfaces without using browser history. Apply the checked-in
`menu-bg.png` as the background image for both the home page and the lobby.

## Context

M5 is complete. The app currently lands on `StatusView` (a dev placeholder) at `/`. The lobby
and four editor/tool pages (`/tools/map-editor`, `/tools/oob-editor`, `/tools/map-test`,
`/tools/table-test`) exist but have no shared navigation. A `menu-bg.png` asset is checked in
to `client/public/`. This track is pure UI/navigation polish for M5.5 — no game logic changes.

## User Story

As a player or developer, I want a welcoming home page with menu links and an in-page
navigation menu on each editor tool, so that I can quickly get to the lobby or switch
between editor surfaces without relying on the browser's back button.
