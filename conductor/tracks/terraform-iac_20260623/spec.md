## Summary

Replace the manual Phase 3 provisioning steps from `m8-notifications_20260622` with a
declarative Terraform config in `infra/`. One `terraform apply` produces a fully-configured
production environment with no manual console steps.

## Context

M8 Phase 3 in `m8-notifications_20260622` is a set of manual DigitalOcean console steps
(provision Droplet, create Spaces bucket, wire GitHub secrets). Those steps are complete
in spirit but fragile — machine switches or re-provisioning require repeating them by hand.
This track encodes them as Terraform so the environment is reproducible and version-controlled.

## Acceptance Criteria

- [ ] `terraform init && terraform apply` from `infra/` provisions a working Droplet, Spaces
      bucket, and Firewall with no manual console steps
- [ ] GitHub secrets (`DO_DROPLET_IP`, `DO_SSH_USER`, `DO_SSH_KEY`) are wired automatically
      via the GitHub Terraform provider
- [ ] `deploy.yml` runs green on next push to `master` after `terraform apply`
- [ ] Terraform state is stored in the Spaces bucket and survives a machine switch
- [ ] `terraform.tfvars` is gitignored; `terraform.tfvars.example` documents all required
      inputs

## Dependencies

- `m8-notifications_20260622` Phase 3 manual steps (the context this replaces)
- Requires: DO personal access token, DO Spaces access key pair, GitHub personal access
  token (for the github Terraform provider)

## Out of Scope

- DNS / domain setup
- TLS / SSL certificate provisioning (nginx config is HTTP-only for now)
- Multiple environments (staging, prod) — single prod environment only
- Terraform modules abstraction — flat config is fine for this scale

## Technical Notes

- Provider pins: `digitalocean` ≥ 2.x, `github` ≥ 6.x
- State backend: Spaces bucket `lob-online-games`, key `tfstate/terraform.tfstate`
- Droplet: Ubuntu 22.04, 2 vCPU / 4 GB, bootstrapped via `cloud-init`
- `cloud-init.yaml` installs Node 20, PM2, nginx, clones repo to `/opt/lob-online`
- Firewall: inbound SSH (22), HTTP (80), app port (3000)
- `.terraform/`, `*.tfstate`, `*.tfstate.backup`, `terraform.tfvars` added to `.gitignore`
