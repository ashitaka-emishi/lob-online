# Specification: M6 UI — Turn Control, ActionPanel Payloads, and About Page

**Track ID:** m6-ui_20260614
**Type:** Feature
**Created:** 2026-06-14
**Status:** Draft

## Summary

Three M5.5 UI tickets that were deferred into the M6 cycle: a turn-control header showing scenario date/time/phase/side (#519), ActionPanel payload wiring for ROLL_INITIATIVE / ISSUE_ORDER / ACTIVATE_STACK (#551), and an About page with game credits (#528).

## Context

M6 combat engine is now merged. The game UI still shows only a minimal turn summary line; players cannot tell the scenario time, cannot submit payload-bearing actions from the UI, and there is no About page. All three issues are tagged M5.5 — they are pure UI/content work with no game-rules coupling.

## Acceptance Criteria

### #519 — Turn Control

- [ ] GameView renders a `TurnControl` component above or near ActionPanel showing scenario date, computed scenario clock time, current turn number, active side, and current phase.
- [ ] Displayed time updates reactively when game state changes.
- [ ] Daytime turns advance in 15-minute increments; night turns in 30-minute increments.
- [ ] Computation uses the existing `lightingSchedule` and `turnStructure` scenario fields — no new duplicate fields.
- [ ] South Mountain scenario remains all-daytime for current gameplay (turns 1–38 = 09:00–18:30).
- [ ] Day visibility is represented as unlimited (999 hexes); night as 2 hexes.
- [ ] `computeTurnTime(turnNumber, scenario)` utility is unit-tested with daytime and night sequences.
- [ ] Component tests cover rendered date, time, active side, and phase.

### #551 — ActionPanel Payloads

- [ ] END_PHASE and END_ACTIVATION remain one-click (no payload required).
- [ ] ROLL_INITIATIVE submits `{ leaderId, unitId }` — leader and unit selectable from UI dropdowns populated by `validActions` candidates.
- [ ] ISSUE_ORDER submits `{ unitId, orderType }` for `attack` or `move` — order type selectable from candidates.
- [ ] ACTIVATE_STACK submits `{ hex }` — hex read from selected stack/hex.
- [ ] UI blocks submission when required payload fields are null or invalid.
- [ ] Payload construction is unit-tested.
- [ ] Disabled/invalid action states are covered by tests.
- [ ] At least one GameView integration test covers a payload-bearing action.
- [ ] No combat or morale UI is introduced.

### #528 — About Page

- [ ] HomeView includes an About button/link.
- [ ] `/about` route renders `AboutView.vue`.
- [ ] Page credits MMP and The Gamers as source lineage.
- [ ] Page links to The Gamers Archive, LoB Series Support, and MMP LoB page.
- [ ] Page includes designer credits (Dean Essig, David A. Powell minimum).
- [ ] Page includes web-app credit: `Line of Battle Online was created by Andrew Hammer using Claude and OpenAI's Codex tools.`
- [ ] Page includes concise unofficial/fan-implementation disclaimer.
- [ ] Tests cover the HomeView About link and rendered About page credits.
