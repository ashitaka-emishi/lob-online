# Specification: Editor Polish — Issues #526 and #527

**Track ID:** editor-polish-526-527_20260608
**Type:** Bug
**Created:** 2026-06-08
**Status:** Draft

## Summary

Two M5.5 editor polish fixes: (1) remove redundant cross-editor nav links that sit beside
primary action buttons in MapEditorView and ScenarioEditorView; (2) extend the scenario
lighting schedule with `visibilityHexes` (integer hexes, 999 = unlimited) and weather
conditions `fog` and `rain`.

## Context

M5.5 is the turn-loop cleanup milestone. The editor tools (map editor, scenario editor)
received a shared `EditorNav` component in PR #520 that provides cross-tool navigation.
However, both views still contain legacy inline `<a>` links beside their primary action
buttons that are now redundant and visually compete with those actions. Separately, the
lighting schedule in `scenario.json` and its Zod schema lack visibility caps and weather
conditions needed for accurate South Mountain scenario modeling.
