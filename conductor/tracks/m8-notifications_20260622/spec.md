## Context

After Track 2 (`m8-persistence_20260622`) the store is production-ready. This track adds the
two remaining M8 deliverables: Discord async notifications (enabling PBEM play) and hex-control

## Technical Notes

- `notifyWebhook(url, payload)` — plain `fetch` POST; catch all errors; fire-and-forget
  (no `await` in the response path of the actions route)
- `buildActionPayload(gameId, action, state)` — Discord embed with game ID, action type,
  turn number, active side
- `DISCORD_WEBHOOK_TEST_URL` overrides `url` when set — lets tests and local dev target the sink
- `updateHexControl(state, hexId, side)` in `engine/vp.js` — SM §5.1 terrain VP
- Droplet provisioning: Ubuntu 22.04, Node.js 20, PM2, nginx; wire 3 GitHub secrets
  (`DO_DROPLET_IP`, `DO_SSH_USER`, `DO_SSH_KEY`) to activate deploy workflow
