# Specification: M8 Local Dev Infrastructure

**Track ID:** m8-local-infra_20260622
**Type:** Feature
**Created:** 2026-06-22
**Status:** Draft

## Summary

Set up local S3-compatible storage (MinIO via Docker) and a Discord webhook sink script so
all subsequent M8 work can be developed and tested without real cloud credentials.

## Context

M8 replaces local-file game state persistence with DigitalOcean Spaces and adds Discord
webhook notifications. Both require external services that aren't available in local dev.
This track provides drop-in local substitutes so the rest of M8 can be implemented and
tested without real cloud accounts.

## Acceptance Criteria

- [ ] `docker compose up -d` starts MinIO accessible at `http://localhost:9000`
- [ ] MinIO console available at `http://localhost:9001` for bucket management
- [ ] `.env.example` documents all new M8 env vars with local dev defaults
- [ ] `npm run discord:sink` starts a local server on port 4040 that logs POST bodies and returns 204
- [ ] `curl -X POST http://localhost:4040 -d '{"test":1}'` prints the body to console

## Dependencies

- Docker / Docker Compose installed locally
- No code dependencies on other M8 tracks

## Out of Scope

- Actual Spaces client code (Track 2)
- Discord notification logic (Track 3)
- Any game engine changes

## Technical Notes

- MinIO image: `minio/minio`; ports 9000 (API) and 9001 (console)
- Volume: `./data/minio` (gitignored)
- `SPACES_FORCE_PATH_STYLE=true` needed for MinIO path-style addressing — document in `.env.example`
- `scripts/discord-test-server.js` — plain Node/Express server, no build step needed
- Add `./data/minio` to `.gitignore`
