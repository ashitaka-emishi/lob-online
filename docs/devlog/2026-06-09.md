## 09:40 — PR: feat(m5.5): multi-module platform (#529)

This PR delivers the multi-module platform — the infrastructure needed for the app to select,
remember, route, load, and edit published-game/module data rather than assuming South Mountain
everywhere. Each module can now hold one or more playable scenario start states. It closes issue
#529 and completes the M5.5 milestone.

The central design decision was to introduce a single authoritative slug→folder map
(`MODULE_FOLDERS` in `moduleFolders.js`) and a `resolveModulePath(slug, file)` function
that all server-side data access flows through. This makes the mapping trivially auditable and
means adding a new module later requires only one line in that map. The `ModuleNotFoundError`
class carries a `status: 404` so Express middleware can surface it cleanly without a separate
lookup.

On the client, `useModuleStore` (Pinia + localStorage) is the single source of truth for the
active module slug. `modulePath(suffix)` and `defaultScenarioPath(suffix)` on the store build
canonical URLs. Editor views read `useRoute().params.moduleSlug` to build API URLs dynamically;
Scenario Editor also reads `scenarioSlug` and saves under
`data/modules/<module>/scenarios/<scenario>/scenario.json`.

Vue Router was extended with module-level editor routes and nested
`/modules/:moduleSlug/scenarios/:scenarioSlug/...` routes for lobby, game, and Scenario Editor,
plus legacy redirect rules from the old flat paths to `THG`/`full-battle` so any bookmarked or
hardcoded links continue to work. Eight scaffold module folders (THG, TTS, AFS, LCV, NBH, TTW,
NTB, IB) were created with Zod-valid placeholder JSON.

A late fix was needed in `vite.config.js`: Vite defaults to reading `.env` from the client
package root (`client/`), but the project `.env` lives at the monorepo root. Adding
`envDir: '..'` makes `VITE_MAP_EDITOR_ENABLED` visible to the browser bundle, which gates the
Editor link on the home page. Non-SM scenario data and full round-trip browser testing are
deferred to M6 when individual scenario editors will be populated.
