## 22:35 — `/team-review` on PR #687: the doc-sync PR repeated its own bug, plus a real find

Before merging, ran `/agent-teams:team-review` (security, performance, architecture
dimensions) against PR #687. Security found the DELETE-route ownership check from #410 was
never actually implemented — only environment-gated (`MAP_EDITOR_ENABLED`) — and that the
closing comment on #410 didn't say so. Filed #688, added a residual-risk comment at

estimate 27 lines from a row this PR had already corrected to 841 — fixed.

Architecture found the big one: "841/841 hexes, 0 unknown" is a self-referential count — true
of `map.json`'s `hexes` array, false as a claim about the South Mountain map. `gridSpec`
declares a 2240-cell (64x35) grid; only 841 cells have any record, almost all in columns 1-30.
Verified independently with `hexNeighbors()` from `server/src/engine/hex.js`: a real BFS shows
6 of the 10 scenario VP hexes are unreachable by the movement pathfinder, which treats
unrecorded hexes as impassable. 75 hexes are missing `elevation`. The `_todoHexes` removal
from earlier today turned out to be justified on a false premise too — the referenced setup
zones were never actually resolved.

Asked whether to fold the coverage-gap fix into this PR or scope it separately; the user
flagged something specific: they remembered having a more complete map checked in at some
point. Git history says otherwise for every tracked path and every branch — 841 hexes, no
exceptions, all the way back. The answer was in `git stash list`: `stash@{0}`, dated
2026-05-23, message "WIP: boundary face fix (#418) + map session data — not committed to PR
#451," never applied, never dropped, just sitting there for two and a half months. It holds a
2261-hex `map.json` (0 unknown, real terrain variety, columns 1-63) plus a genuine schema/engine
fix — "boundary mirror faces," letting map-edge hexes store their own edge-face data since
they have no neighbor hex to canonically own it, which is invisible on today's sparse map and
only surfaces once hexes near the true map boundary are populated. That's almost certainly why
this got stashed instead of merged and then forgotten while the multi-module platform split
and M9 moved past it on an older, smaller base.
