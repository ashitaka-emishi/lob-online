# 2026-06-06

## 07:54 — PR: Debt Sprint to 10 + M5 Closeout

This PR bundles two completed conductor tracks: the `debt-sprint-to-10` debt cleanup sprint and
the `m5-closeout` documentation pass. Together they bring the codebase fully current before M5.5
work begins.

The debt sprint targeted the 10 fixable items remaining after PR #516 closed the Phase 1 test
gaps. The four Phase 2 code fixes were the most substantive. `#503` turned out to be a test gap
rather than a missing guard — `requireSide` already enforced `session.gameId === req.params.id`
returning 401; the fix was adding an explicit cross-game test so that protection is covered.
`#504` added parity tests confirming the server (`hexNeighborInDir` + numeric face indices) and
client (`adjacentHexId` + direction strings) implementations of `stripNonPlayableBoundaryEdges`
produce identical mutations — this will catch any future divergence before it reaches production.
`#505` replaced `:disabled="pending"` on ActionPanel buttons with `:aria-disabled` so buttons
remain in the tab order and focusable during submission, plus a `watch(pending)` + `nextTick`
focus restoration when the pending state clears. `#502` extracted `refreshValidActions` and its
`serverValidActions` ref out of `GameView.vue` into `useGameStore`, guarded by a new
`_actionsGeneration` counter so burst `game:state-updated` socket events only apply the last
fetch result.

Phase 3 trivial closures were mostly housekeeping: checking off spec acceptance criteria in the
OOB editor track (`#511`), adding `rows="6"` to the specialRules textarea (`#512`), and formally
closing four issues that are either won't-fix or blocked on later milestones (`#469` `#385` `#205`
`#204`). The final net open debt score entering M6 is 12 — all six remaining items are
milestone-blocked on M6 or M8 and cannot be addressed until those surfaces exist.

The M5 closeout track was purely documentation and GitHub housekeeping. It created
`docs/testing/m5-closeout-checklist.md` (manual verification steps for the game shell),
`docs/milestones/m5-closeout.md` (a formal record of what M5 delivered, what is intentionally
stubbed, and what moves to M5.5/M6/M7), updated the HLD milestone table and status heading, and
closed the M5 GitHub milestone after reassigning the six blocked issues to their correct target
milestones. The M5 GitHub milestone is now closed with 0 open issues.

One note on scope: the debt sprint plan targeted "score 32 → 10" but landed at 12. The two-point
gap is because `#205` and `#204` were already closed before the sprint ran — they appeared in the
register snapshot used to write the spec but had been cleaned up by the time the register was
consulted. The 12-pt floor is the true pre-M6 baseline.
